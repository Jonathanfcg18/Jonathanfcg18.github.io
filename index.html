¿Quién soy yo?

Soy un estudiante de Ingeniería en Sistemas enfocado en el desarrollo de software y el aprendizaje continuo de tecnologías relacionadas con programación, redes y arquitectura de sistemas. Me caracterizo por tener un enfoque analítico y estructurado para resolver problemas, lo que me permite comprender tanto la lógica del código como el funcionamiento de los sistemas en su conjunto.

Tengo experiencia trabajando con control de versiones (Git), entornos de desarrollo como IntelliJ IDEA, Vs Code y prácticas de calidad de software como TDD (Test-Driven Development), aplicando pruebas unitarias y uso de mocks para validar funcionalidades. Además, he desarrollado habilidades en bases de datos, especialmente en SQL, donde busco no solo implementar consultas, sino optimizarlas y estructurarlas de manera clara y eficiente.

Actualmente, también estoy fortaleciendo mis conocimientos en redes y ciberseguridad, realizando prácticas con herramientas como Wireshark, FTP y entornos virtualizados, lo que me permite tener una visión más completa del funcionamiento de los sistemas informáticos.

Me considero una persona autodidacta, disciplinada y orientada a la mejora continua. Busco constantemente aprender nuevas tecnologías y aplicar buenas prácticas de desarrollo para construir soluciones sólidas, escalables y bien estructuradas.

Portafolio

  • Sistema de Gestión de Cine

    Aplicación de consola para gestión de películas, funciones y reserva de asientos.

    Implementa control de disponibilidad, validación de entradas y persistencia de datos mediante archivos.

    Arquitectura modular con separación en .h y .cpp.

    Stack: C++, manejo de archivos, estructuras de datos, programación modular.

  • Sistema de Gestión de Choferes

    Aplicación para la administración de choferes con operaciones CRUD sobre base de datos relacional.

    Implementa conexión a base de datos, consultas SQL y validación de datos desde la capa de aplicación.

    Estructura organizada por capas (lógica y acceso a datos).

    Stack: Java, SQL, JDBC, CRUD, arquitectura por capas.

  • Sistema de Gestión de Ayudantes FIS-EPN

    Aplicación de escritorio con interfaz gráfica para la gestión de ayudantes de investigación en la Facultad de Ingeniería de Sistemas de la EPN.

    Implementa roles diferenciados (Jefa de Departamento y Director de Proyecto), flujo de solicitud y aprobación de ayudantes, registro de horas, reportes y sistema de notificaciones.

    Aplica el patrón MVC con capa DAO para la persistencia, y los patrones Singleton para entidades clave del dominio.

    Stack: Java, Swing, SQLite, JDBC, patrón MVC, patrón DAO, PlantUML (diagramas UML).

  • Juego de Horror en Primera Persona

    Implementa sistema de iluminación dinámica con focos cuadrados, física de colisiones, mecánica de recolección de objetos con UI interactiva, y narrativa audiovisual con control de música y efectos de sonido mediante SDL_mixer.

    Incluye menú principal, sistema de pausa, pantalla de carga animada y cinemática final.

    Arquitectura modular con shaders GLSL personalizados, carga de modelos 3D (GLTF/OBJ), sistema de partículas para lluvia, y máquina de estados para control de gameplay.

    Stack: C++, OpenGL, GLFW, GLM, ImGui, SDL_mixer, GLSL, asincronía de audio, diseño orientado a objetos.
